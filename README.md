# Погодный дайджест

Консольная утилита на Node.js: получает прогноз погоды для одного или нескольких
городов через Open-Meteo и сохраняет отчёт в JSON.

## Требования

- Node.js >= 20
- npm

## Установка

```bash
git clone https://github.com/<логин>/weather-digest.git
cd weather-digest
npm install
cp .env.example .env
```
